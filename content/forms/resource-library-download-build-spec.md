A single, reusable form for distributing free resources (the Always Enough Workbook, the AI
Without Fear guide), with a dropdown to select which resource, so new resources can be added
without a new form each time.

**Routing**

- Immediate resource delivery: an instant download link on the confirmation screen, or an
  automated email via **SendPulse**.
- List management: every submission adds the subscriber to SendPulse with a tag for which
  resource they downloaded, for future targeted communications.
- Optional backup: a spreadsheet log (name, email, resource, date).

**Consent**: a required checkbox — "I'd like to receive this resource and occasional emails from
Always ENOUGH™. I can unsubscribe at any time. See the Privacy Policy." Submission is blocked
until checked.
