# Stage 04 — Frontend build

**In**: `docs/PAGE_BLUEPRINTS.md`, the design system from Stage 03.

**Do**: Build each page in `src/app/`, using the components from Stage 03 and content from
`content/`. Every piece gets three tests as it's built: does it work, does it connect to the
rest of the site, and what happens when something goes wrong (bad input, slow network, missing
image).

**Out**: working pages, deployed to a preview URL, not production.

**Done when**: every page in the sitemap exists, is responsive, and passes a first read-through
of `docs/INSPECTION_CHECKLIST.md`.

**Do not look at**: production DNS, analytics setup, launch tasks — not yet.
